## 📍 프로젝트 소개

- 해당 프로젝트는  '오늘의 집' 핵심 요구사항을 분석하여, 대규모 트래픽에서 안정적인 성능 확보를 목표로 하였습니다.
- 실서비스 수준의 백엔드 고도화를 통해 확장성과 안정성을 갖춘 전자상거래·커뮤니티 백엔드를 구축
